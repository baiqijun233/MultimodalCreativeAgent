# 上线适配清单

当前项目代码、测试、容器和本地真实链路已经完成。正式上线前只需要把下面的运行环境适配到目标服务器，不需要再改主业务代码。

## 必填适配

1. 准备 Docker、Redis 和持久化磁盘，挂载 `/data`，保证 SQLite、视频和图片资产不会随容器删除；不要使用 `docker compose down -v`。
2. 在服务器的密钥管理系统中注入 `DEEPSEEK_API_KEY` 和 `ARTCLAW_API_KEY_ACCOUNT_A`；不要写入代码、镜像、日志或 Git。
3. 按目标网络环境设置 `DEEPSEEK_BASE_URL`、`ARTCLAW_BASE_URL` 和 `API_PORT`。默认地址已经写入 Compose，可不改。
   如需无密钥独立验收，可设置 `MODEL_PROVIDER=offline`，任务会使用内置离线模型，不调用 DeepSeek。
4. 启动后检查 `GET /health` 与 `GET /ready`，确认模型、ArtClaw、Redis 和数据库状态。
5. 若启用可选图片生成，再额外注入 `IMAGE_API_BASE_URL` 和 `IMAGE_API_KEY`；不启用时无需配置。

## 上线验收

```powershell
docker compose -f 02_Source\docker-compose.yml up -d --build
Invoke-RestMethod http://127.0.0.1:8001/health
Invoke-RestMethod http://127.0.0.1:8001/ready
```

完成后用网页控制台创建一个小任务，确认任务状态为 `succeeded`；视频或图片生成仍必须显式确认可能产生费用。正式环境应通过反向代理提供 HTTPS，并将服务器防火墙、域名和证书接入现有运维体系。

## 本项目已完成

- DeepSeek 真实规划链路和结构化结果校验。
- ArtClaw 账户查询、最低成本视频生成、轮询和下载。
- 可选图片服务适配、分批幂等、本地落盘和资产读取。
- 网页控制台、任务列表、过期清理、路径隔离。
- SQLite 检查点、失败重试、Redis/Celery/WebSocket 本地联调。
- 代码已内置 Redis 跨进程付费提交锁、SQLite 额度审计和 `/metrics` 基础指标；服务器只需提供 Redis 连接与日志/监控采集配置。
- 对象存储本轮按需求暂缓，继续使用本地 `/data`，后续如需多实例或大文件再做供应商适配。
- 统一健康信息、就绪探针、容器健康检查、自动化测试和敏感值扫描。
